# BJJ Absolute Class Analysis

This project combines my passions for Brazilian Jiu Jitsu, Data Engineering, and Data Analysis.
Using my data skills to answer the question:

> "What is the minimum weight a competitor needs to be to have a realistic chance at winning the absolute class at a major tournament?"

You can find the current version of the website and analysis here:
[BJJ Absolute Class Analysis](https://grantwooley.github.io/BJJ-Absolute-Class-Analysis/) *(Website functional, but project still in development.)*

The project is structured into three parts:

1. Data Engineering
2. Data Analysis
3. Website Creation

###### Technologies Used

- Python: Web scraping, ETL pipeline development, data processing
- R: Data cleaning, statistical analysis, visualization (`ggplot2`)
- Quarto: Reproducible website publishing
- GitHub Pages: Website deployment

### 1. Data Engineering 🔨

---

Python is used to perform ETL of the IBJJF Tournament results.

* All Python source code can be found in the `Python` directory.

1. The tournament data is extracted via web scraping tournament results directly from IBJJF's website: [IBJJF Results](https://ibjjf.com/events/results)
2. Basic transformations and filters are done on the tournament data. Balancing keeping the data raw and close to source, while making it more analysis-friendly.
3. Tournament data is then loaded into `.csv` files for easy ingestion of analysis code.
   - The raw dataset can be found on Kaggle: [IBJJF Major Tournament Black Belt Results](https://www.kaggle.com/datasets/grantwooley/ibjjf-major-tournament-black-belt-results)

### 2. Data Analysis 📊

---

R is used to clean, analyze, and visualize the data.

* All R source code can be found in the `R` directory.

1. `Data_Cleansing.R` ingests all the `.csv` files, cleaning and wrangling the data to be ready for analysis. Saving data.tables as `.rds` files.
2. `IBJJF_Analysis.R` loads the `.rds` files. Performing analysis and creating visualizations.
   * All visualizations (ggplot2 plots) are saved as `.rds` files for easy loading into Quarto files.

### 3. Website Creation ✈️

---

The final website [BJJ Absolute Class Analysis](https://grantwooley.github.io/BJJ-Absolute-Class-Analysis/) is built using Quarto and hosted via GitHub Pages

* Quarto being a publishing system that integrates well with R and Python. Used for quickly developing websites that combine text, code, data analysis, and visualizations in a single, reproducible workflow. [Official Quarto website](https://quarto.org/)
* The way Quarto works is all Quarto source code is stored as `.qmd` files in the root of the project directory.
  * Generated website assets are stored in the `images` and `docs` directories.

I use Quarto to run and display the data visualizations alongside an extensive write-up of each visual. Analyzing what the visuals and data suggests ultimately determining what the data says about the original question.

> "What is the minimum weight a competitor needs to be to have a realistic chance at winning the absolute class at a major tournament?"

I also include a Data Details page explaining some basic details of Brazilian Jiu Jitsu for those unfamiliar with the sport. Along with key points regarding the source data that influenced the final analysis.

#### Project Structure 🏭

---

1. Python and R source code are stored in their respective `Python` and `R` directories.
2. Quarto source code is stored in the root of the project directory. (`.qmd` files)
3. All data is stored in the `data` directory. Cleaned data `.rds` files in the directory. Raw `.csv` files in the `raw_data` subdirectory. Visualizations in the `plots` subdirectory.
4. `img` directory contains all image files not generated by Quarto used on the website.
